# 富文本与源码模式

<span class="version-badge">适用于 HorseMD v0.13.51</span>

点击状态栏中的“富文本/源码”，或按 `Ctrl/Cmd+/` 切换模式。

![HorseMD 源码模式](/images/v0.12.10/source-mode.png)
<span class="image-caption">源码模式保留 Markdown 标记，适合检查语法、批量编辑或处理复杂结构。</span>

## 两种切换行为

HorseMD 会根据你是否正在编辑决定定位方式：

1. 光标在可视区域内：切换后跟随对应光标，保证光标仍然可见。
2. 没有可见光标，只是在滚动阅读：切换后保持当前阅读视口，不会突然跳到旧光标。

表格单元格、行内代码、行内公式、代码块和重复文字使用结构化位置映射，不依赖简单关键词搜索。富文本编辑器在源码模式下保持挂载，因此切回时不会重新解析整篇文档或重新加载远程图片。超长文档在纯阅读切换时只恢复当前视口，不会为了不可见的旧光标重新扫描整篇文档；在公式附近编辑时，光标也会跟随同一段文字。

## 源码 + 预览（桌面）

在富文本编辑区右键，选择“**源码 + 预览**”。同一份文件会在左侧显示 Markdown 源码、右侧显示富文本效果：

- 在左侧写 Markdown，短暂停顿后右侧会更新预览；
- 右侧只用于预览、滚动、选中和复制；编辑、格式化、评阅与右键操作都在左侧源码完成；
- 拖动中间分隔线可调整两边宽度；
- 两侧滚动会按当前段落联动。图片、表格和代码块的高度不同，因此目标是定位到同一段内容，而不是让两个滚动条机械地处于相同比例；两侧到底时的尾部阅读留白保持一致；
- 右侧预览不会显示编辑右键菜单；右上角的“关闭预览”会直接回到普通富文本视图。状态栏的“富文本/源码”仍可用于进入单一源码视图；
- 源码中的加粗光标完整显示在字符边界前。无论是首行还是中间非空行，都可以直接点击首个字符的起始区域（例如 `## 页面对应关系` 的第一个 `#`）并在该字符前输入。

该模式只在桌面 Markdown 文档中提供。纯文本、未加载富文本的超大文档，以及已经开启“两份文件分屏”时不会显示。

## 源码编辑与保存状态

只切换模式不会把标签标记为“已修改”。在源码文本框真正输入、删除或粘贴后，新内容才会同步回富文本并进入未保存状态。Windows 文档常用的 CRLF、UTF-8 BOM 和文件中已有的混合换行也会保留；在源码中只改一处，不会顺带统一整篇换行格式。

在富文本中只修改局部文字时，HorseMD 会保留未修改区域原本的 Markdown 写法，例如空行、列表标记、必要的转义和图片替代文字。`![图片说明](图片地址)` 在富文本编辑、保存或切换源码后仍会保留“图片说明”，不会被尺寸值替换。将 Markdown 源码直接粘贴到富文本中时，即使复制来源同时带有网页格式，也会优先保留原始 Markdown；从微信公众号等网页粘贴图文时则保留网页的标题、格式和图片，单独图片粘贴后也可以直接切换源码、保存并重新打开。进行标题层级、列表类型等跨区块结构调整时，受影响的区块可能会按 Markdown 规范重新生成；需要逐字符控制复杂语法时，请使用源码模式。

连续有序列表统一使用标准的 `1.` 写法。若富文本操作暂时产生了标准 Markdown 无法单独表达的相邻有序列表，HorseMD 会在富文本中合并为同一连续列表，不会在源码中插入 `1)` 或隐藏注释；在一个有后续条目的列表中从空项退出、再按 `Enter` 也会按这一规则收敛。相同操作发生在嵌套有序列表时，会写成标准的空父项与缩进子列表，因此后续编号和正文可以正常保存。作者原本写成 `1)` 的列表，以及源码中原有的独立 `<br />`，仍会保留原样。

新建空文件可以从标题开始，也可以直接点击正文起笔。直接写正文时，编辑器初始界面中未使用的空标题不会写入源码，也不会导致保存暂停；已经存在于作者 Markdown 中的空标题不会因此被删除。

从列表末尾开始写普通正文时，先在最后一项末尾按 `Enter` 产生空列表项，再按一次 `Backspace` 退出列表，然后直接输入正文。此时如果不输入文字而再次按 `Backspace`，空段落会重新并回上一列表项；随后再按 `Enter` 出现新的列表序号是正常结果。要重新退出，在这个新的空列表项再按一次 `Backspace` 即可。

如果在列表项正文开头输入看起来像下一层列表的文字，例如 `2. 测试` 或 `- 测试`，源码可能显示为 `2\. 测试` 或 `\- 测试`。这些是 Markdown 为保持“普通正文”结构所需的转义，不会出现在富文本中；去掉后，重新打开文件可能会变成嵌套列表。

段落、引用和列表项末尾新输入的普通 ASCII 空格会按字面空格保存，不再改写成 `&#x20;`。行首若需要保留空格，源码使用标准 `&nbsp;` 表示第一个空格，余下空格保持字面值；这是通用 Markdown/HTML 能识别的写法，不会写入 HorseMD 专用零宽字符，也避免被解析为缩进代码块。

空任务项会保存为普通列表文本 `* [ ]` 或 `* [x]`（并保留原有的列表 marker）。GFM 没有“空复选框”的标准源码：裸写法会被所有 GFM 工具理解为普通文字列表。因此 HorseMD 不写 `&nbsp;`、HTML 数字实体或私有标记来伪造 checkbox；重新打开后它同样显示为普通列表文字。

如果空段落的第一个内容，或标题文本的行首/行尾，是 Tab，源码会使用标准 `&#x9;` 表示这个真实制表符。直接写原始边界 Tab 会被通用 Markdown 当作结构或格式空白；数值字符引用可由其他 Markdown/HTML 工具正常解码，不依赖 HorseMD 专用标记。标题边界的普通空格仍遵循同一源码规则：行首为 `&nbsp;`，行尾保持字面空格。

在两个已有内容块之间按 `Enter` 新建空段落时，HorseMD 会把它保存为额外的标准 Markdown 空白行，不会写入 `<br />`、注释或私有字符。若直接把这行输入为列表，列表会取代这个空段槽位，不会在列表前多留一段空白。连续空白行保留在源码和磁盘中；按通用 Markdown 规则重新进入富文本时，它们可能显示为同一个段落间隔。

切换源码、保存和导出前，HorseMD 会用与富文本编辑器相同的 Markdown parser 验证待提交源码。合法的非满行表格会先形成稳定的 editor-only 结构，但源码仍保留作者原来的短行写法；表格里的转义竖线和手动 `<br>` 也不会被当作普通分隔符或内部占位，包括单独位于 cell 中或位于 cell 文字末尾的换行。每次富文本编辑、保存和切换都绑定到同一个编辑 revision，较晚到达的旧回调不能覆盖新内容。代码块语言名称和围栏中“像表格”的文字不会改变这些同步规则。

若严格验证仍无法提交，应用会先询问是否用当前富文本重建源码；重建也失败或被取消时，可以把当前画面另存为 `.horsemd-recovered.md`。恢复副本只写用户选择的新路径，原文件不变；它用于救回可见内容，可能规范化空行、marker 和转义，不能替代作者原始源码。表格恢复会按保存时仍可证明的 cell 坐标移除编辑器内部空占位，不会全局删除用户手写的 `<br />`；坐标身份仍可证明的恢复表格可在冷重开后继续编辑和保存，无法证明时仍会安全暂停并保留两侧内容。

源码模式支持 `Ctrl/Cmd+F` 查找，当前结果会高亮并滚动到可见区域。从富文本带着查找栏切换过来时，HorseMD 会为新视图重建匹配结果。

## 实验性：源码权威内核

状态栏“富文本/源码”按钮旁有一个小的 ▾ 菜单，可以为**当前标签页**单独打开“源码权威内核”实验开关。开启后编辑操作直接作用于 Markdown 源码本身，而不是先改富文本再回写源码。

### 当前支持

- 段落与标题文字编辑（含段首按 `Enter` 在光标前插入空行、块尾连续按 `Enter` 每次新增一行空白，语义已修正）。
- 列表族（有序/无序/任务列表）的输入与结构操作、任务复选框勾选。
- 代码块正文编辑（文字输入、换行、删除，含引用/列表嵌套的代码块；Windows 风格 `\r\n` 与单独 `\r` 换行的围栏同样可编辑，行尾拼写按原样保留）、代码块语言切换、`Mod-Enter` 退出代码块。
- **加粗/斜体/删除线/行内代码**的施加与撤销（工具栏、右键菜单、快捷键三条路径一致；含行内代码的文档挂载映射正常，不再降级），以及加粗等格式文字之后段落内其余位置的普通打字。
- **引用/取消引用**（右键块菜单，段落、标题、列表整块与松散列表均可用，源码内核开关开/关行为一致）。
- **数学公式**：含行内 `$x^2$` 与多行 `$$ … $$` 块级公式的文档现在可以正常挂载并编辑其余部分，不再整篇退回普通模式。块级公式本身仍是只读的。
- **行内 HTML 片段**：含 `<span>…</span>` 等片段的文档正常挂载，不再整篇退回普通模式；在片段外按 `Enter`/`Backspace` 等结构操作正常。同一段落里**片段以外的位置现在可以正常打字**（含紧贴片段左右两侧），整段片段也可以整体选中删除或替换；只有把片段删掉一半这种拆开语法的操作会被拒绝——同行内公式、行内图片。
- **黄色高亮**：`==黄色高亮==` 所在段落可以正常编辑；工具栏的黄色高亮按钮可以施加与撤销。
- **表格单元格文字**：可以直接在单元格里输入与删除；`Tab`/`Shift-Tab` 仍是跨单元格移动光标，不会写入任何字节；分隔行与对齐写法逐字节不变。
- **图片地址**：源码里已经写了空的 `![]()` 时，可以在图片输入框里填写地址。**图片的替代文字（alt）与标题（title）目前没有界面入口**——底层改写命令已经就绪，但没有任何按钮或输入框会派发它们，请不要去界面上寻找；需要改这两项请切到源码模式直接编辑。
- **链接**：选中文字 → 工具栏链接按钮 → 在浮层里输入网址 → 确认，以及修改已有链接的网址、移除链接，全部直接写源码。
- 输入法（IME）合成、撤销/重做（含代码块内的撤销/重做）、保存与冷重开。
- **单个区块降级**：某个区块无法安全映射时，现在只把**那一个区块**变成只读并单独提示，文档其余部分照常编辑，不再整篇退回普通模式。

### 暂不支持

限制分三类，**影响范围完全不同**，请对照区分。

#### 一、整篇文档用不了内核（该标签页自动退回普通模式）

文档里只要出现下面任意一种写法，内核就不接管这篇文档。此时该标签页的行为与没打开开关时**完全一样**——照常编辑、照常保存，只是这次开关没有生效：

- 独占一行的 `$$公式$$`（改写成 `$$`、公式、`$$` 三行即可正常使用）；
- 写在列表项**里面**的块级公式或代码围栏（写在列表外面正常）；
- 两个直接相邻、中间只隔一个空行的根级 `<div>` 块（中间插入一段正文即可正常）。

#### 二、只有某一处变成只读（文档其余部分照常编辑）

这类写法不影响整篇文档，只是**那一处**不能改，并会单独给出“此段落在内核模式下暂为只读”的提示：

- 红色/蓝色高亮所在的那一段（它们以 `<mark class="hm-hl-…">` 形式保存；黄色高亮不受影响，可以正常编辑）；
- 含 `<br>` 换行或转义 `\|` 竖线的表格单元格——**只有该单元格**只读，同表其它单元格照常输入；
- 列数参差或超出映射能力的表格——**整张表**只读，但文档里表格以外的部分照常编辑；
- 含**硬换行**（行尾两个空格或反斜杠换行）的那一段暂时不能直接打字——整段都不能（该段的 `Enter`/`Backspace` 等结构操作仍然可用）。行内公式、行内图片、行内 HTML 片段不再属于这一类：这些段落现在可以正常打字，选中整个公式/图片/片段按 `Backspace` 删除也可以（连同前后文字一起删同样可以）。只有两种情况仍被拒绝：把某个公式/图片/片段拆开一半，或删除**带链接的图片**（它的 `[` 与 `](链接)` 不属于图片本身，单删图片会留下孤立的链接符号）。

#### 三、被拒绝的操作（提示后不生效，不会损坏文档）

- 块级公式与 mermaid/LaTeX 预览块的内容编辑、块级 HTML 的编辑。
- 表格的行列增删、对齐切换、新建表格。
- 图片的图注（caption）与拖拽缩放比例——它们属于富文本显示状态，不写进源码。
- 评阅（CriticMarkup）标记。
- 给一个裸网址加高亮。
- 直接在加粗/斜体等已有标记文字内部继续输入（“续加粗”手势）。
- 斜杠 `/` 插入菜单（含用斜杠新建代码块；`/quote` 例外，但只在光标所在整块内容恰好是刚输入的查询文字时可用——对已有正文段落或列表使用 `/quote` 会被拒绝，这是架构性限制，引用一段已有内容请改用右键菜单的“引用/取消引用”）。
- 右键列表/块类型转换。
- 在少数 `\r\n`/`\r` 换行代码块里按 `Enter` 换行——只有一行（或空）内容的代码块，以及块内换行风格不统一、且第一行用 LF 结尾的代码块（这两种情况下块内的普通文字输入和删除都不受影响，只是不能在块内换行）。

这些操作在关闭该开关时和平时完全一样。

这个开关只属于当前标签页的这次会话，不写入设置或工作区状态；关闭标签页、重开应用后需要重新打开。

## 行内代码的键盘移动

光标位于行内代码（如 `` `示例` ``）首尾时，按 `←` 或 `→` 可以回到相邻正文，继续按方向键会正常穿过前后的文字。不会为了“退出代码”跳过字符、插入隐藏字符或改变原 Markdown。

::: tip 大文档
超大文档可能默认使用快速源码模式。确认设备性能足够后，可以选择进入富文本；图片很多的文档首次渲染需要更多时间。
:::
